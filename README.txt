SOBHITNEXORA website
====================

Files:
- index.html: complete responsive one-page website.

Before publishing:
1. Replace the sample email link (hello@sobhitnexora.example) with your real public contact email, or remove that button.
2. Add real PDF/notes links in the Education cards when you have them.
3. Check the YouTube channel link.

Free publishing:
- GitHub Pages: create a public repository, upload index.html, then open Settings > Pages and publish from the main branch.
- Netlify: sign in, then deploy the folder containing index.html.

A free hosting URL will be provided by the hosting platform. A custom .com domain is separate and usually costs money.
